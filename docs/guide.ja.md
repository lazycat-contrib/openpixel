# 作品を自分のバージョンに変える

## まず一つ動かしてみる

作品を選び、`works/<slug>/index.html` を開きます。デモを眺めたら、[作品の操作説明](works.ja.md)に沿って操作してください。起動手順は [README](../README.ja.md#start) にあります。

| ファイル | 用途 |
|---|---|
| `index.html` | 実行画面と操作コントロール |
| `source.html` | 読み取り専用のソース表示 |
| `source.js` | 編集するソースコード |

再利用するときは作品フォルダー全体をコピーし、ページ、ソース、ライセンスの相対位置を保ってください。

## 小さな変更から始める

1. 作品フォルダーをバックアップ、またはコピーします。
2. `source.js` で中国語の原題やシーン識別子を検索します。各作品の中国語 README にも目安の行番号があります。
3. 作品のモジュールを見つけ、`init`、`tick`、`draw` などの対応する処理を読みます。
4. 色、大きさ、速度などを一つだけ変え、再読み込みして結果を確認します。
5. デモと手動操作の両方を確認します。

同じファイルに共通の描画・再生コードもあります。依存関係を保ちながら作品部分を変更してください。

## 試せる改造

| 作品 | 最初の変更 | 変更後の確認 |
|---|---|---|
| 夜の池 | 夜景を夕暮れの配色にする | 波紋、映り込み、錦鯉が反応するか |
| 磁性流体 | 液体とハイライトの色を変える | 突起と反射が滑らかにつながるか |
| 動き出すパズル | 空や建物の配色を変える | 組み立てと乗り物の動きがつながるか |
| サンセット・ループ | 空と道路の色を変える | 遠近感、運転、カメラが動くか |
| 銀河の衝突 | 銀河の色やシーンの数値を変える | 軌跡がつながり、負荷が許容範囲か |

これらは改造の例です。すべてのモデルで同じ結果が得られることを保証するものではありません。

## コーディング支援ツールを使う

原プロジェクトは Claude の支援を受けて制作しました。GPT、Gemini などを使う場合も、**作品フォルダー全体**と具体的な目標、残したい動作を伝えてください。

```text
対象：夜の池。
index.html、source.js、README を読み、実行の仕組みを説明してください。
波紋、餌やり、魚の移動、デモ、一時停止を保ち、夜景を夕暮れの配色にしてください。
対象作品に必要なコードだけを変更し、外部 API・画像・フォント・依存関係を追加しないでください。
変更箇所を説明し、デモと手動操作の両方を確認してください。
```

先に説明を求めてから変更し、毎回ブラウザで実際の動きを確かめてください。

## よくある質問

**ファイルを開くと真っ白になる、表示がおかしい。** リポジトリのフォルダーで `python -m http.server 8080 --bind 127.0.0.1` を実行し、[ローカルの作品集](http://127.0.0.1:8080)を開いてください。`source.js` が `index.html` と同じフォルダーにあるかも確認します。

**音が出ない。** ブラウザがクリックを要求する場合があります。画面か音声コントロールを押してください。音のない作品もあります。

**スマートフォンで操作しにくい。** タッチ対応は作品ごとに異なります。戦闘やドライブの操作は主にデスクトップのキーボードとマウス向けです。

**中国語の表示が残っている。** 翻訳対象はリポジトリの説明と操作ガイドです。作品内の表示、ソースコメント、各作品の原文説明は主に中国語のままです。

**PC や再起動のたびに見た目が変わる。** システムフォントと乱数による差があります。

**自分のプロジェクトで利用できる？** コードは [MIT](../LICENSE) で公開しています。著作権表示とライセンス文を残してください。
