# 나만의 버전으로 바꾸기

## 먼저 작품 하나를 실행하세요

작품을 골라 `works/<slug>/index.html`을 엽니다. 데모를 본 다음 [작품 조작 안내](works.ko.md)에 따라 직접 조작해 보세요. 실행 방법은 [README](../README.ko.md#start)에 있습니다.

| 파일 | 용도 |
|---|---|
| `index.html` | 작품 실행 화면과 컨트롤 |
| `source.html` | 읽기 전용 소스 뷰어 |
| `source.js` | 수정할 소스 코드 |

재사용할 때는 작품 폴더 전체를 복사하고 페이지, 소스, 라이선스의 상대 위치를 유지하세요.

## 작은 변경부터 시작하세요

1. 작품 폴더를 백업하거나 복사합니다.
2. `source.js`에서 중국어 원제나 장면 식별자를 검색합니다. 작품별 중국어 README에도 시작할 위치의 줄 번호가 있습니다.
3. 작품 모듈을 찾아 `init`, `tick`, `draw` 등 해당 함수를 읽습니다.
4. 색상, 크기, 속도 중 하나만 바꾸고 새로고침해 결과를 확인합니다.
5. 데모와 수동 조작을 모두 확인합니다.

같은 파일에 공통 그리기·재생 코드도 있습니다. 의존 관계를 유지하면서 작품 모듈을 수정하세요.

## 시도해 볼 수정

| 작품 | 첫 번째 수정 | 수정 후 확인 |
|---|---|---|
| 밤의 연못 | 밤 풍경을 노을 색상으로 바꾸기 | 물결, 반사, 비단잉어가 반응하는지 |
| 자성유체 | 액체와 하이라이트 색상 바꾸기 | 돌기와 반사가 자연스럽게 이어지는지 |
| 살아 움직이는 퍼즐 | 하늘과 건물 색상 바꾸기 | 조립 과정과 차량 이동이 이어지는지 |
| 노을 순환도로 | 하늘과 도로 색상 바꾸기 | 원근감, 운전, 카메라가 작동하는지 |
| 은하 충돌 | 은하 색상과 장면 수치 바꾸기 | 궤적이 이어지고 성능에 문제가 없는지 |

시작을 위한 예시이며, 모든 코딩 모델이 같은 결과를 낸다는 뜻은 아닙니다.

## 코딩 도우미와 함께 수정하기

원본 프로젝트는 Claude의 도움을 받아 제작했습니다. GPT, Gemini 등을 사용할 때도 **작품 폴더 전체**, 구체적인 목표, 유지할 동작을 전달하세요.

```text
대상: 밤의 연못.
index.html, source.js, README를 읽고 장면이 실행되는 방식을 설명해주세요.
물결, 먹이 주기, 물고기 이동, 데모, 일시 정지를 유지하며 밤 풍경을 노을 색상으로 바꿔주세요.
대상 작품에 필요한 코드만 수정하고 외부 API, 이미지, 글꼴, 의존성은 추가하지 마세요.
변경 위치를 설명하고 데모와 수동 조작을 모두 확인해주세요.
```

먼저 설명을 요청한 뒤 수정하고, 변경할 때마다 브라우저에서 실제 동작을 확인하세요.

## 자주 묻는 질문

**파일을 열면 화면이 비거나 이상하게 나와요.** 저장소 폴더에서 `python -m http.server 8080 --bind 127.0.0.1`을 실행하고 [로컬 작품 모음](http://127.0.0.1:8080)을 여세요. `source.js`가 `index.html`과 같은 폴더에 있는지도 확인하세요.

**소리가 안 나요.** 브라우저에서 먼저 클릭해야 할 수 있습니다. 화면이나 소리 컨트롤을 눌러 보세요. 소리가 없는 작품도 있습니다.

**휴대전화에서 조작하기 어려워요.** 터치 지원은 작품마다 다릅니다. 전투와 운전은 주로 데스크톱 키보드와 마우스에 맞춰져 있습니다.

**중국어가 남아 있어요.** 번역 범위는 저장소 설명과 조작 가이드입니다. 작품 내 UI, 소스 주석, 작품별 원문 설명은 주로 중국어입니다.

**컴퓨터나 재시작에 따라 화면이 달라요.** 시스템 글꼴과 무작위 요소 때문에 차이가 생길 수 있습니다.

**제 프로젝트에 사용해도 되나요?** 코드는 [MIT](../LICENSE)로 공개하며, 저작권 표시와 라이선스 문구를 유지해야 합니다.
