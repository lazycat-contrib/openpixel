# 把作品改成自己的版本

## 先跑通一个作品

从合集里挑一个，打开对应 `works/<目录>/index.html`。先看自动演示，再按页面说明接管操作。运行步骤见[首页](../README.md#开始运行)。

每件作品都有三种入口：

| 文件 | 用途 |
|---|---|
| `index.html` | 运行画面与操作控件 |
| `source.html` | 用浏览器阅读源码；这是只读页面 |
| `source.js` | 用文本编辑器或编程工具修改代码 |

不要只复制 `index.html`。独立复用时复制整件作品目录，保留页面、源码及许可证的相对位置。

## 从一个小改动开始

1. 备份或复制作品目录。
2. 在 `source.js` 中搜索作品名，或查看该作品 `README.md` 标注的位置。
3. 找到该作品的注册和模块，阅读 `init`、`tick`、`draw` 等对应函数。
4. 只改一个颜色、尺寸或速度参数。刷新运行页，确认效果后再继续。
5. 同时检查演示与手动操作，避免只改好其中一种模式。

公共绘制工具与播放控件也在源码内。优先修改当前作品的模块，保留公共依赖。

## 可以尝试的方向

| 作品 | 第一次修改可以做什么 | 操作后检查什么 |
|---|---|---|
| 夜池 | 把夜景改成日落，调整桥和水面的配色 | 点水后涟漪、倒影与锦鲤是否仍响应 |
| 磁流体 | 调整液体颜色与高光风格 | 移动磁场时尖峰和反光是否连续 |
| 活拼图 | 调整拼好后的天空与建筑配色 | 从散片到完成、车辆运动是否仍衔接 |
| 落日环线 | 改变天空和道路的色调 | 道路透视、驾驶操作和视角是否正常 |
| 星系相撞 | 调整星系颜色和场景参数 | 轨迹是否连续，浏览器性能是否可接受 |

这些是修改建议，不是跨模型一键复现的承诺。

## 用编程助手继续修改

原项目由 Claude 辅助编程制作。使用 GPT、Gemini 或其他助手时，提供**一个完整作品目录**，说明目标和需要保留的行为。

可直接改写下面这段需求：

```text
目标作品：夜池。
先阅读 index.html、source.js 和 README.md，说明作品如何运行。
将画面从夜景改成日落配色，保留点水、投食、鱼群移动、演示和暂停功能。
只修改当前作品需要的代码，不引入外部接口、图片、字体或运行依赖。
完成后说明改动位置，并分别检查自动演示与手动操作。
```

让助手先解释再修改，比一次改动多个系统更容易判断结果。每次修改后都要在浏览器里实际运行。

## 常见问题

**双击页面后显示异常或没有画面。** 用本地服务器运行：在仓库目录执行 `python -m http.server 8080 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8080`。也检查 `source.js` 是否与页面在同一目录。

**没有声音。** 浏览器可能阻止自动播放音频；先点击画面或声音控件。部分作品本身不含音效。

**手机上难以操作。** 部分作品支持触摸；战斗、驾驶等场景的完整操作主要面向桌面键鼠。页面里的控件说明是具体依据。

**不同电脑上的文字或每次重开画面不完全一样。** 本辑使用系统字体，并保留部分随机过程，因此可能出现差异。

**能否用于自己的项目？** 代码使用 MIT 许可，复用时保留[版权和许可证](../LICENSE)。
